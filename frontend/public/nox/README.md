# Assets d’évolution de Nox

actuel reste la source officielle pendant la Phase 1.5. Les futures illustrations
pourront être ajoutées dans `squire/`, `young-knight/`, `knight/`, `captain/`,
`commander/` et `grandmaster/` sans modifier les règles de progression.
